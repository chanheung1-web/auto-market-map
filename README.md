# auto-market-map

自動車バリューチェーンの世界動向を1画面で見る個人用ダッシュボード。

完成車から素材まで120社超の株価を Yahoo Finance から取り、
世界地図で地域ごとの温度感を、一覧で銘柄ごとの動きを見る。
隣の `auto-industry-watcher` が毎朝ためている業界ニュースとダイジェストを、
銘柄に紐づけて表示する。

## 起動

デスクトップの **AutoMarketMap**（地球儀のアイコン）をダブルクリックする。
サーバーが立ち上がり、準備できた時点でブラウザが自動で開く。初回は10秒ほどかかる。

同じことをフォルダからやるなら `start-app.bat`、手動なら `npm run dev -- -p 3002`。

**サーバーは自動起動しない。**PCを再起動したら、また同じショートカットを押す必要がある。
一度押してあれば、iPhone からも同時に見られる。

ショートカットが無い／プロジェクトを移動した場合は作り直せる（管理者権限は不要）:

```
powershell -ExecutionPolicy Bypass -File create-shortcut.ps1
```

## 画面の見方

**重要トピック**（ページ上部）は `auto-industry-watcher` の週次・日次ダイジェスト。
週次は「今週の3大トピック」まで人手で絞り込んだ論点なので、個別ニュースより先に読む。

**階層タブ**（全階層 / 完成車 / 部品 / 電池 / 半導体 / ソフトウェア / 素材）
を切り替えると、地図の色も一覧も同時に絞られる。
「半導体だけが売られた日」のような層特有の動きが、地域別に見える。

**サプライチェーン**は部品カテゴリ15件の構造マップ。市場規模・CAGR・上位5社の
シェアと、その企業が何で勝っているかが入っている。「上位3社67%」のような
寡占度バッジが付くので、どの層が押さえられているかが一目で分かる。
青い社名は監視銘柄に紐づいており、押すとニュースが絞り込まれる。
数字は2024年基準の調査会社推計で、**カテゴリ間で足して「市場合計」を作れない**
（調査会社ごとに市場の定義が違うため）。

**地図のバッジ**はその地域の監視銘柄の騰落率の**単純平均**。
自動車株には地域別の既製指数がないので自前で集計している。
指数の代用ではなく、監視対象がどう広がって動いたかを示すもの。
`3↑ 7↓` は上げた銘柄数と下げた銘柄数で、平均だけでは潰れる「割れ方」を補う。
バッジを押すとその地域だけに絞り込む。

**価格の下の時刻**はその値段が実際に約定した時刻（日本時間）。
固定バーの「取得」＝アプリが読みに行った時刻とは別物で、市場が閉じていれば
前営業日のままになる。深夜に見れば米国株は現在時刻、日本株は前日15:30 と並ぶ。

**一覧の銘柄**を押すと、下の個別ニュースがその企業に紐づくものだけになる。
`news 3` バッジは直近60日で紐づくニュースの件数。
`保有 200` は実際の保有株数、`ウォッチ` はウォッチリスト登録済み。

## 銘柄の追加・削除

「＋ 銘柄を追加」から、この画面で監視対象を増やせる。
**社名でも証券コードでも検索できる**（「東海理化」「6995」「Aptiv」いずれも可）。
検索結果から選ぶ方式なので、シンボルを手打ちする必要はない。

- 追加した銘柄の `✕` は**実体を削除**する（戻せない）
- 組み込み銘柄の `✕` は**非表示**にするだけで、一覧上部の「非表示中」から戻せる

保存先は `data/custom-companies.json`（サーバー側）。
localStorage ではないので、PCで追加した銘柄は iPhone からも見える。

## iPhone / iPad から見る

1回だけ管理者権限で:

```
powershell -ExecutionPolicy Bypass -File setup-firewall.ps1
```

そのあと `start-app.bat` を実行しておけば、iPhone から
`http://desktop-2v0387k:3002`（繋がらなければ `http://100.113.78.45:3002`）で開ける。
Tailscale 経由のみ通り、物理ネットワーク側は閉じたまま。

## データの出どころ

| 何 | どこから | 更新 |
| --- | --- | --- |
| 株価・騰落率 | Yahoo Finance の非公式 chart API（キー不要） | 60秒ごと |
| 個別ニュース | `../auto-industry-watcher/data/news/*.jsonl` | 初回のみ・直近60日 |
| 重要トピック | `../auto-industry-watcher/reports/{weekly,daily}/*.md` | 初回のみ |
| 保有・ウォッチ | `../stock-trading-app/data/{holdings,watchlist}.json` | 5分ごと |
| 銘柄マスタ | `src/lib/companies.ts` ＋ `data/custom-companies.json` | 手動 |
| サプライチェーン構造 | `src/lib/supplyChain.ts`（Excelから変換した2024年基準の静的データ） | 手動 |

いずれも隣フォルダをファイルとして直接読んでいる（GitHub API ではないのでトークン不要）。
**この2つの隣フォルダとの相対位置を変えると壊れる。**

株価は参考値で遅延・欠損がある。投資助言を目的としたものではない。

## 注意している点

- 保有情報はこのアプリに持たない。`stock-trading-app` が正本で、コピーを持つと必ず古くなる。
- 銘柄マスタは自動更新されない。**Yahoo が 404 を返し始めたら上場廃止・分割・統合のサイン**。
- `code: null` は非上場（ボッシュ、ZF、ティアフォー等）。株価は取らないが業界構造の理解に必要なので一覧には残す。
- `auto-industry-watcher` へは**読み取りしかしない**。あちらは追記のみで履歴を守る規約で動いている。

設計上の前提と、触るときに踏みやすい罠は `AGENTS.md` にまとめてある。
